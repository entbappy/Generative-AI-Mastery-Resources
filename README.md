## Introduction

This repository contains a curated collection of resources for learning and mastering Generative AI technologies, including Large Language Models (LLMs), embeddings, vector databases, and more. Whether you're a beginner or an experienced practitioner, you'll find valuable materials to enhance your knowledge and skills in this rapidly evolving field.

## Repository Structure

The repository is organized into the following main sections:

- [Complete Guide to Open AI](./Complete%20Guide%20to%20Open%20AI) - Resources for working with OpenAI's models and APIs
- [Data Preprocessing and Embeddings](./Data%20Preprocessing%20and%20Embeddings) - Techniques for preparing data and creating embeddings
- [End to End Projects](./End%20to%20End%20Projects) - Complete project implementations using Generative AI
- [Fine Tuning LLMs](./Fine%20Tuning%20LLMs) - Methods and examples for fine-tuning language models
- [Huggingface Platform and its API](./Huggingface%20Platform%20and%20its%20API) - Working with Huggingface's ecosystem
- [LangChain - Basic to Advance](./LangChain%20-%20Basic%20to%20Advance) - Tutorials on using LangChain framework
- [Learn to use Open Source LLMs](./Learn%20to%20use%20Open%20Source%20LLMs) - Working with open-source language models
- [LlamaIndex - Basic to Advance](./LlamaIndex%20-%20Basic%20to%20Advance) - Guides for using LlamaIndex
- [LLMOps](./LLMOps) - Operations and deployment of LLM applications
- [Master Vector Database for LLMs](./Master%20Vector%20Database%20for%20LLMs) - Working with vector databases
- [Retrieval Augmented Generation (RAG)](./Retrieval%20Augmented%20Generation%20\(RAG\)) - Implementing RAG systems

## Contributing

Contributions to this repository are welcome! If you have resources, tutorials, or projects related to Generative AI that you'd like to share:

1. Fork the repository
2. Create a new branch (`git checkout -b feature/add-new-resource`)
3. Add your resources to the appropriate directory
4. Commit your changes (`git commit -am 'Add new resource on [topic]'`)
5. Push to the branch (`git push origin feature/add-new-resource`)
6. Create a new Pull Request

Please ensure your contributions are well-organized and include appropriate documentation.
